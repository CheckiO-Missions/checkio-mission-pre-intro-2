1. Lassen Sie uns zwei neue Variablen namens add, multi einführen. Weisen Sie ihnen Ausdrücke der Summe (+) bzw. des Produkts (*) der zuvor deklarierten Variablen robots, droids zu. Wenn Sie Probleme haben, verwenden Sie die Hinweise unter der Beschreibung.

Sie können robots, droids anpassen und dann Check Solution drücken. Wenn Sie add, multi richtig ausdrücken, werden Sie diese Aufgabe trotzdem erfolgreich abschließen.
